خدمة الأمير - النسخة المحسنة

المحتوى:
- لوحة تحكم RTL متجاوبة للكمبيوتر والموبايل.
- إدارة المخدومين: إضافة، تعديل، حذف، بحث، وملف تفصيلي.
- إدارة الفصول.
- تسجيل الحضور: حاضر / متأخر / غائب حسب التاريخ والفصل.
- الافتقاد: تسجيل تم الافتقاد / لم يتم.
- أعياد الميلاد والإحصائيات.
- QR للمخدوم وتجربة تسجيل عبر ID.
- نسخ احتياطي واسترجاع JSON وتصدير/استيراد Excel.
- إعدادات الإشعارات، إضاءة الشاشة، الوضع الليلي، الخصوصية، المساعدة، وعن الموقع.
- صفحة عن الموقع: نبذة عن الموقع، الإصدار، والتطوير PK.

التشغيل:
1) افتح index.html مباشرة أو شغل مجلد المشروع من خلال خادم محلي.
2) البيانات الحالية محفوظة محليًا في LocalStorage داخل نفس المتصفح والجهاز.
3) النسخة الحالية لا تحتوي على خادم مركزي أو حسابات متعددة الأجهزة؛ يلزم Backend وقاعدة بيانات واختبار ضغط قبل النشر العام.

ملاحظات الإصدار:
- تم إصلاح تسمية «عن التطبيق» إلى «عن الموقع».
- تم إضافة تحقق من الاسم وID ومنع تكرار ID.
- تم تحسين التحقق من تواريخ الحضور والافتقاد.
- تم تحسين حساب التاريخ المحلي وأعياد الميلاد ذات البيانات غير الصحيحة.

تشغيل الخادم المركزي:
1) ثبّت Node.js 18 أو أحدث.
2) افتح Terminal داخل مجلد khedmet_work.
3) شغّل: npm start
4) افتح: http://localhost:3000

ملاحظات مهمة:
- الخادم يحفظ البيانات في data/db.json ويتيح مزامنة المتصفحات على نفس الخادم.
- هذه طبقة تشغيل أولية بدون حسابات وصلاحيات متقدمة؛ قبل النشر العام يجب إضافة تسجيل دخول حقيقي، HTTPS، قاعدة بيانات إنتاجية، نسخ احتياطية مجدولة، تحديد معدل الطلبات، واختبار ضغط.

تسجيل الدخول:
- التسجيل والدخول برقم الهاتف المصري وكلمة مرور لا تقل عن 8 أحرف.
- كلمة المرور تُحفظ كـ hash باستخدام scrypt ولا تُحفظ كنص صريح.
- خيار «تذكرني» يستخدم جلسة موقعة صالحة حتى 30 يومًا.
- أول حساب يتم تسجيله يحصل على دور admin، والحسابات التالية user.
- قبل النشر العام يُنصح باستخدام PostgreSQL/Redis، HTTPS، reverse proxy، ومراقبة واختبار ضغط.
